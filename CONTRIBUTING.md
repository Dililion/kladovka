# Contributing to Kladovka

Спасибо за интерес к проекту! Мы приветствуем любой вклад.

## Как внести вклад

### Сообщить об ошибке

1. Проверьте, что проблема еще не была описана в [Issues](https://github.com/YOUR_USERNAME/kladovka/issues)
2. Создайте новый Issue с подробным описанием:
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Скриншоты (если применимо)
   - Версия браузера/ОС

### Предложить новую функцию

1. Создайте Issue с тегом `enhancement`
2. Опишите функцию и почему она будет полезна
3. Предложите возможную реализацию

### Отправить Pull Request

1. Fork репозиторий
2. Создайте ветку от `main`:
   ```bash
   git checkout -b feature/my-feature
   ```
3. Внесите изменения
4. Убедитесь, что код компилируется без ошибок
5. Напишите понятные commit-сообщения
6. Push в свой fork:
   ```bash
   git push origin feature/my-feature
   ```
7. Создайте Pull Request

## Стандарты кода

### TypeScript
- Используйте строгую типизацию
- Избегайте `any` где возможно
- Именуйте переменные понятно и по-английски

### React
- Используйте функциональные компоненты с хуками
- Извлекайте переиспользуемую логику в custom hooks
- Держите компоненты небольшими и сфокусированными

### Git commits
Используйте понятные сообщения:
- `feat: добавить экспорт в PDF`
- `fix: исправить ошибку поиска по тегам`
- `docs: обновить README`
- `refactor: переписать компонент загрузки файлов`

## Тестирование

Перед отправкой PR убедитесь:
- Backend компилируется: `cd backend && npm run build`
- Frontend компилируется: `cd frontend && npm run build`
- Приложение запускается: `./start.sh`
- Основные функции работают

## Вопросы?

Не стесняйтесь задавать вопросы в Issues!
